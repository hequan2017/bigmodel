# 检索增强生成（RAG）入门

## 为什么需要 RAG

大语言模型的知识来自训练数据，存在两点局限：知识有截止时间，且无法
访问机构内部资料。检索增强生成（Retrieval-Augmented Generation，RAG）
在回答前先从知识库检索相关资料，把资料作为上下文交给模型，从而
显著降低幻觉并支持私有知识问答。

## RAG 的基本流程

1. 文档切分：把长文档切成若干片段（chunk），保留位置信息。
2. 向量化：用嵌入模型（Embedding）把每个片段转成向量。
3. 检索：用户提问同样转向量，在向量库中找出最相近的片段。
4. 生成：把检索到的片段与问题一起交给大模型生成回答。

## 关键实践要点

- 切分粒度影响效果：片段过大稀释要点，过小丢失上下文。
- 引用必须可回溯：回答应标注来源片段，便于核对原文。
- 无依据时应当拒答：检索不到相关资料时，应明确说明而非编造。

## 与微调的选择

RAG 适合知识频繁更新、需要引用来源的场景；微调适合改变模型的行为
风格或补充稳定的领域能力。两者可以组合使用。
